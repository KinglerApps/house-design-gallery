# House design gallery

Twenty-six whole-house renovation concepts, 178 whole-house image boards plus seven reference-inspired garden boards, room galleries, side-by-side comparisons, a favourites moodboard with share links, 22 dimensioned garden plans, itemized cost estimates and downloadable feedback.

Plain static HTML, CSS and JavaScript. Open `index.html` locally, or use GitHub Pages from the root of the `main` branch. `.nojekyll` preserves the file structure.

Concept visuals and planning allowances are for review, not surveyed construction drawings or contractor quotations.

The public site contains only the curated review package. Original house photographs, measurements, briefs, generation prompts and maintenance scripts are kept outside this repository.
