# House design gallery

Twenty-six whole-house renovation concepts, 178 whole-house image boards plus seven reference-inspired garden boards and the 20 supplied Maple 2 reference photos with the source PDF, room galleries, side-by-side comparisons, a favourites moodboard with share links, 22 dimensioned garden plans, the original floor-plan PDF and interactive 2D/3D house model, a three-style design walkthrough, a separate Photorealistic tab with 12 new fixed room reconstructions for Roman Luxury and Boutique Hotel plus access to existing room references, itemized cost estimates and downloadable feedback.

Plain static HTML, CSS and JavaScript. Open `index.html` locally, or use GitHub Pages from the root of the `main` branch. `.nojekyll` preserves the file structure.

Concept visuals and planning allowances are for review, not surveyed construction drawings or contractor quotations.

The public site contains only the curated review package. Original house photographs, measurement spreadsheets, briefs, generation prompts and maintenance scripts are kept outside this repository.

## Shopping list

[Shopping List.html](Shopping%20List.html#garden-tables) contains 20 oval and elliptical garden dining designs in concrete, microcement, ceramic and stone. The comparison distinguishes the planned 180 × 90 cm footprint, custom-size candidates, compact alternatives and larger options. Quote-only products and unconfirmed UAE supply are labelled. Prices and source pages were reviewed on 5 November 2026.

[Garden Table Options.html](Garden%20Table%20Options.html) is the self-contained HTML export for downloading or sharing. Product and supplier links open in new tabs and work without JavaScript. Search, footprint/material filters, and price sorting are available.
